Workstation setup

1. Install Python

Download Python from python.org. On Windows, make sure the Python launcher is installed. Open PowerShell and try py --version (or python --version).

2. Install VS Code

Download Visual Studio Code from code.visualstudio.com. Create a folder named Directorate inside Documents.

3. Download your diagnostic package

Save both files into the same Directorate folder. The activation file is unique to your Agent account.

4. Run the diagnostic

Open workstation_diagnostic.py in VS Code. Open its terminal, make sure the terminal is in the same folder as both files, and run:

py workstation_diagnostic.py

If py isn't recognized, try python workstation_diagnostic.py. Ask ARGUS for help if anything goes wrong.

5. Transmit activation response

Copy the 64-character response printed by your Python program and paste it below.
